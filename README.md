# Hussain's Machine Learning and Engineering Portfolio

This repository contains a curated set of machine learning and engineering projects. The projects cover signal classification, Kaggle-style tabular modeling, and an Industry 4.0 IoT dashboard prototype.

## Projects

| Project | Summary | Key Skills |
| --- | --- | --- |
| [GPLA-12 Acoustic Leakage Classification](Projects/gpla-12-acoustic-classification/README.md) | Acoustic gas pipeline leakage classification using GaussianNB, a PyTorch 1D CNN, and a simple ensemble. | Signal classification, neural networks, model evaluation, ensemble modeling |
| [Kaggle Tabular Classification](Projects/kaggle-tabular-classification/README.md) | Team-of-two Kaggle competition project that ranked 7th with a submission F1 score of `0.74698`. | EDA, imbalanced classification, SMOTE, XGBoost, threshold tuning |
| [Industry 4.0 IoT Dashboard](Projects/industry4-iot-dashboard/README.md) | Flask dashboard prototype for smart-manufacturing monitoring scenarios using sensor data and myRIO/LabVIEW acquisition prototypes. | Flask, SQLAlchemy, dashboards, sensor data, industrial IoT |
